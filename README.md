## Selected Projects

### 1. [ComplianceRAG](https://github.com/Faraz6180/ComplianceRAG)
**Retrieval-Augmented Generation with Groundedness Checking**

A RAG application exploring how to assess whether generated answers are supported by retrieved source material.

- **Problem:** Fluent answers can contain claims that are not adequately supported by retrieved documents.
- **Approach:** Combines document retrieval, answer generation, sentence-level groundedness critique, and citation validation.
- **Engineering focus:** Evidence attribution, unsupported claims, and flagging low-confidence results for human review.
- **Technologies:** Python, Gradio, FAISS, Sentence Transformers, Hugging Face Inference API, PyPDF.

[Source code](https://github.com/Faraz6180/ComplianceRAG) · [Live demo](https://huggingface.co/spaces/Faraz618/ComplianceRAG)

## Engineering Principles

- **A working demo is the starting point.** Successful execution alone does not establish correctness.
- **Evaluate the complete system.** Retrieval, context construction, generation, and downstream decisions can fail independently.
- **Treat model outputs as claims to verify.** Plausibility is not evidence of correctness.
- **Make uncertainty visible.** Systems should be able to flag unsupported or low-confidence outputs when appropriate.
- **Document limitations honestly.** Clear constraints help reviewers understand what a system does and does not establish.

These principles guide the direction of my work; individual projects should be evaluated against the evidence in their repositories.
